# Control de juego para familias

Un servicio para que las familias ayuden a un familiar con adicción al juego a
dejar de apostar. El teléfono de la persona queda administrado: no tiene
apuestas, bancos ni billeteras, y para instalar una app o abrir un sitio le
pide permiso a un tutor.
